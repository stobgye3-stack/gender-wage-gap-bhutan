# Data access

This project uses Bhutan Labour Force Survey microdata for 2011-2022. The authors do not redistribute the raw or processed microdata because access is subject to permission from the official data provider. Researchers wishing to replicate the analysis should request access directly from the provider. After access is granted, place the pooled dataset in `data/raw/lfs_2011_2022_pooled.dta` and run `00_master.do`.
